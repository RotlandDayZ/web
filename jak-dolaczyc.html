How to join

Kilka prostych kroków dzieli Cię od pierwszej nocy w Rotland. Zainstaluj mody, znajdź serwer i wskocz do gry.

Możesz dołączyć na dwa sposoby

A few simple steps stand between you and your first night in Rotland. Install the mods, find the server and jump in.

You can join the server in two ways

1. Oficjalny DayZ Launcher

1. Install DayZ and mods

• Uruchom DayZ Launcher.

• Open the DayZ Launcher.

• Przejdź do zakładki Community.

• Go to the Community tab.

• Wyszukaj serwer Rotland.

• Search for Rotland.

• Wybierz nasz serwer i kliknij Dołącz

• Select our server and click Join.

• Launcher automatycznie pobierze wszystkie wymagane mody.

• The launcher will automatically download all required mods.

• Po zakończeniu pobierania uruchom grę i dołącz na serwer.

• Once the download is complete, launch the game and join the server.

Jeżeli serwer nie pojawia się na liście, możesz wyszukać go po adresie IP:

If the server does not appear in the list, you can search for it using the IP address:

DZSA Launcher

DZSA Launcher

2. Pobierz i zainstaluj DZSA Launcher.

2. Download and instal DZSA Launcher.

• W wyszukiwarce wpisz Rotland.

• Type Rotland into the search bar.

• Wybierz nasz serwer z listy.

• Select our server from the list.

• Kliknij Play.

• Click Play.

DZSA Launcher automatycznie pobierze brakujące mody i uruchomi grę z odpowiednią konfiguracją.

DZSA Launcher will automatically download any missing mods and start the game with the correct configuration.

Dołącz do Discorda

4. Join our Discord

Na Discordzie znajdziesz aktualne ogłoszenia, wsparcie administracji oraz możliwość zgłaszania graczy łamiących regulamin.

On Discord you'll find current announcements, admin support and the ability to report rule-breaking players.

5. Zapoznaj się z regulaminem

5. Read the rules

Zanim zaczniesz grać, przeczytaj pełen regulamin serwera — znajomość zasad chroni Cię przed niespodziewaną karą.

Before you start playing, read the full server rules — knowing them protects you from an unexpected ban.
