How to join

Kilka prostych kroków dzieli Cię od pierwszej nocy w Rotland. Zainstaluj mody, znajdź serwer i wskocz do gry.

A few simple steps stand between you and your first night in Rotland. Install the mods, find the server and jump in.

SERVER ADDRESS

1. Zainstaluj DayZ i Steam Workshop

1. Install DayZ and Steam Workshop

Upewnij się, że masz zainstalowaną najnowszą wersję DayZ przez Steam. Mody instalujemy bezpośrednio z poziomu launchera gry lub Steam Workshop.

Make sure you have the latest version of DayZ installed via Steam. Mods are installed directly from the in-game launcher or Steam Workshop.

2. Pobierz wymagane modyfikacje

2. Download the required mods

Poniżej znajdziesz listę modów wymaganych do gry na Rotland. Uzupełnij ją o własne nazwy i linki do Steam Workshop.

Below is the list of mods required to play on Rotland. Fill it in with your own mod names and Steam Workshop links.

  • Nazwa modu #1 — krótki opis
  • Mod name #1 — short description
  • Nazwa modu #2 — krótki opis
  • Mod name #2 — short description
  • Nazwa modu #3 — krótki opis
  • Mod name #3 — short description
DO UZUPEŁNIENIA: podmień listę modów na aktualną kolekcję Steam Workshop swojego serwera.
TO FILL IN: replace the mod list with your server's actual Steam Workshop collection.

3. Znajdź serwer

3. Find the server

Otwórz przeglądarkę serwerów w DayZ i wyszukaj „Rotland”, lub połącz się bezpośrednio wpisując adres IP podany powyżej.

Open the DayZ server browser and search for "Rotland", or connect directly using the IP address above.

4. Dołącz do Discorda

4. Join our Discord

Na Discordzie znajdziesz aktualne ogłoszenia, wsparcie administracji oraz możliwość zgłaszania graczy łamiących regulamin.

On Discord you'll find current announcements, admin support and the ability to report rule-breaking players.

5. Zapoznaj się z regulaminem

5. Read the rules

Zanim zaczniesz grać, przeczytaj pełen regulamin serwera — znajomość zasad chroni Cię przed niespodziewaną karą.

Before you start playing, read the full server rules — knowing them protects you from an unexpected ban.
